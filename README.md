Releaf Book

Releaf Book is a second-hand book platform created to help students buy and sell used books easily. Many students have books that are no longer useful after a semester, while others need the same books but cannot afford new ones. This project aims to connect such users on a single platform.

The main idea of Releaf Book is to encourage the reuse of books instead of letting them remain unused or thrown away. By doing this, the platform helps reduce the cost of education and also supports sustainable use of resources.

Users can list the books they want to sell with basic details such as book name, subject, and condition. Other users can search for required books and contact the seller directly. This makes the exchange process simple and transparent.

Releaf Book is designed mainly for students, but it can be used by anyone who wants to buy or sell second-hand books. The project focuses on affordability, accessibility, and reuse rather than profit.

This repository contains the source code and related files for the Releaf Book project.
